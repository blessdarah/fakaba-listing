# Fakaba Listings

Fakaba v2 — built with [Expo](https://expo.dev) and Expo Router, styled with plain React Native `StyleSheet` and the tokens in `theme/`.

## Getting Started

### Installation

1. Install the dependencies:

```sh
yarn
```

2. Start the Metro server:

```sh
yarn start
```

### Running the app

You can run the app on your phone or emulator:

```sh
yarn android
```

or

```sh
yarn ios
```

### Building the app

To build the app for production, run:

```sh
yarn build
```

The output can be found in the `dist` folder.
